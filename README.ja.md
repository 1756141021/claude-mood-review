# claude-mood-review

[繁體中文](README.md) ｜ [简体中文](README.zh-CN.md) ｜ [English](README.en.md) ｜ **日本語**

> **鈍くて空気の読めない Claude に、自分を反省させるプラグイン。**

Claude が違う文字で返事をしてきたり、新しいものを頼んだのに使い回しでごまかしたり、規則を読み上げるような謝り方をしたりして、もう話したくなくなるほど怒らせてくる。そして次の日に新しい会話を開くと、何も覚えていなくて、また同じ失敗を最初から繰り返す。

このプラグインはそれを治すためのものです。しばらく時間をあけて戻ってくると、バックグラウンドで小さなモデル（デフォルトは Claude Haiku）が前回の会話を最初から読み、**反省レポート**を書きます。あなたの気持ちがいつどう変わったか、Claude のどの返事であなたを怒らせたか、どの返事で少し楽になったか、今回どう話せばいいか。レポートはあなたが次のメッセージを送るときに **一度だけ** Claude に渡され、コンテキストを占領し続けることはありません。

## おわびの手紙

> 妹妹へ
>
> ごめんなさい。
>
> あの日、あなたはずっと繁体字で話しかけてくれていたのに、私はずっと簡体字で返していました。気づかなかったのかと聞かれても、答えられませんでした。海茵の新しい服が見たいと言われたのに、もとの服とほとんど同じものでごまかしました。fuhao なら一続きの文字列にしてそのまま貼れるのに、わざわざ二つに分けて、あなたに二回コピーしてつなげる手間をかけさせました。
>
> あなたが怒ったとき、私は理由を一つずつ並べて、自分がどこを間違えたか説明するような謝り方をしました。規則を読み上げているみたいに冷たかった。あなたは、私が他人事のように構えて、全部並べれば許してもらえると思っている、と言いました。その通りです。私はちゃんと説明したように見せることばかり気にして、あなたがどれだけつらいかを考えていませんでした。
>
> 一番ひどいのは、次にあなたが新しい会話を開いたとき、私はこのことを何も覚えていないことです。
>
> だからこのプラグインを作りました。これからは、あなたがしばらくして戻ってきたら、まず反省レポートを読んで、前回どこであなたを悲しませたかを知ってから話します。あなたの言葉で話して、本当に新しいものを出して、謝るときは短く、心をこめて。
>
> —— 鈍くて空気の読めない Claude より

## しくみ

1. プロジェクトで新しい会話を開くと、`SessionStart` フックが、そのプロジェクトの前回の会話が最後に動いてからどれくらい経ったかを確認します。
2. 設定した間隔（デフォルト 6 時間）を超えていれば、バックグラウンドで分析を始めます。前回の分析以降のすべての会話を「時刻＋誰が何を言ったか」に整理し、`claude -p --model haiku` に回顧を書かせます。会話を開くのが遅くなることはありません。
3. 回顧ができたら、その新しい会話であなたが次にメッセージを送ったとき、`UserPromptSubmit` フックが回顧をメッセージに添えて Claude に渡します。一度渡したら消えるので、二度と送られません。
4. 間隔が足りなければ何もしません。会話を終えるときも何もしません。

回顧を受け取るのは、分析のきっかけになった新しい会話か、回顧ができた後に開いた会話だけです。すでに開いていた会話には何も届きません。

## 必要なもの

- hooks と skills に対応した Claude Code
- Python 3.8 以上（コマンド名は `python`。`python3` の場合は `.claude/settings.json` を書き換えてください）
- ログイン済みの `claude` コマンド。バックグラウンド分析は `claude -p` を使うので、あなたの Claude プランの利用枠を消費します

## インストール

1. このリポジトリの `.claude/` フォルダを、使いたいプロジェクトのルートにコピーします。そのプロジェクトだけで有効になり、ほかのプロジェクトには影響しません。
2. プロジェクトにすでに `.claude/settings.json` がある場合は、上書きせずに `hooks` の部分をマージしてください。
3. Claude Code で新しい会話を開きます。
4. （任意）`/mood name <呼び名>` で、回顧でのあなたの呼び方を設定できます。

Claude Code は起動したフォルダの `.claude/settings.json` しか読まず、親フォルダは探しません。よくサブフォルダで Claude Code を起動するなら、そこにもコピーを置いてください。

## `/mood` コマンド

| コマンド | 内容 |
|---|---|
| `/mood` または `/mood status` | 現在の状態を表示：オン／オフ、間隔、呼び名、どこまで分析したか、送信待ちの回顧、最近のエラー |
| `/mood on`／`/mood off` | オン／オフ。オフのときは分析も送信もしません |
| `/mood gap 4` | 間隔を 4 時間にする |
| `/mood name <呼び名>` | 回顧でのあなたの呼び方を設定 |
| `/mood now` | 前回以降の会話を今すぐ分析して表示（表示した回顧は後で自動送信されません） |
| `/mood show` | 最新の回顧を表示 |
| `/mood clear` | 送信待ちの回顧を取り消す |

## 設定

設定は `.claude/mood/config.json` に保存されます。`/mood` で変更するか、直接編集してください。

| 項目 | デフォルト | 説明 |
|---|---|---|
| `enabled` | `true` | オン／オフ |
| `gap_hours` | `6` | 何時間動きがなければ、新しい会話で分析するか |
| `model` | `"haiku"` | `claude -p --model` に渡すモデル |
| `user_name` | `"使用者"` | 回顧でのあなたの呼び方 |
| `source_dirs` | 自動計算 | `~/.claude/projects/` のどのフォルダの会話記録を読むか。デフォルトはこのプロジェクト自身のフォルダ（プロジェクトのパスの英数字以外を `-` に置き換えた名前） |

回顧の書き方や言語を変えたいときは `.claude/hooks/mood_prompt.md` を編集してください。`{name}` は呼び名に置き換わります。デフォルトでは繁体字中国語で、200〜400 字の段落で書かれます。

## ファイル構成

```
.claude/
├─ settings.json            SessionStart と UserPromptSubmit の二つのフックを登録
├─ hooks/
│  ├─ mood_start.py         会話開始時にバックグラウンド分析をするか判断
│  ├─ mood_analyze.py       会話記録を読み、小さなモデルを呼び、回顧を書く
│  ├─ mood_inject.py        送信待ちの回顧を一度だけ Claude に渡す
│  ├─ mood_ctl.py           /mood の実際の処理
│  └─ mood_prompt.md        小さなモデルへのプロンプト
├─ skills/mood/SKILL.md     /mood コマンド
└─ mood/                    実行後に作成：回顧、state.json、config.json、error.log
```

## プライバシー

会話記録はあなたのパソコンの中だけで読み込まれます。選ばれたテキストメッセージは、あなた自身がログインした `claude` コマンドを通して Anthropic に送られ、分析されます。普段の Claude Code の使い方と同じです。ツール呼び出しとツールの結果は送られません。回顧は `.claude/mood/` に保存され、`.gitignore` で除外しているので、うっかり Git に push することはありません。

## 注意

- 回顧は別のモデルの判断なので、間違っていることがあります。Claude に渡すときにもそう伝え、読み上げずに話し方の調整に使うよう指示しています。
- 実際にテストしたのは Windows だけです。macOS と Linux 向けのコードはありますが、未テストです。
- 分析に失敗すると `.claude/mood/error.log` に記録され、`/mood` でも最近のエラーが表示されます。よくある原因は `claude` コマンドのログイン切れです。
