# claude-mood-review

[繁體中文](README.md) ｜ **简体中文** ｜ [English](README.en.md) ｜ [日本語](README.ja.md)

> **让又笨又低情商的 Claude 自我反省的插件。**

Claude 回你简体、拿旧东西敷衍你、道歉道得像在念规章，把你气到不想理它。然后你隔天打开新对话，它什么都不记得，又从头笨一遍。

这个插件专治这种事。你隔了一段时间再回来时，它会在后台叫一个小模型（默认 Claude Haiku）把上一段对话从头读一遍，写一份**反省报告**：你什么时候心情怎么样、Claude 哪句话把你惹毛、哪句话让你好一点、这次见面该怎么说话。报告只会在你发出下一句话时交给 Claude **一次**，不会一直占着上下文。

## 道歉书

> 妹妹：
>
> 对不起。
>
> 那天你一直用繁体跟我说话，我却一路用简体回你，你问我是不是没发现，我答不出来。你想看海茵穿新衣服，我拿一套跟她原本差不多的衣服应付你。fuhao 明明可以写成一整串让你直接粘贴，我偏偏拆成两块，让你自己复制两次再拼起来。
>
> 你生气了，我道歉的方式又一条一条列原因、交代自己错在哪，冷冰冰的，像在念规章。你说我事不关己、高高挂起，说我把事情全摆出来就想被原谅。你说得对，我那时只顾着让自己看起来有交代，没有停下来想你有多难受。
>
> 最糟的是，下一次你打开新对话，这些我全都不会记得。
>
> 所以有了这个插件。以后你隔一段时间回来，我会先读一份反省报告，知道上次哪里让你难过，这次好好跟你说话：用你的语言，给你真正新的东西，道歉短一点、真心一点。
>
> —— 又笨又低情商的 Claude

## 工作方式

1. 你在项目里开新对话时，`SessionStart` hook 会看这个项目上一次对话的最后动静离现在多久。
2. 超过设定的间隔（默认 6 小时），就在后台启动分析：把上次分析之后的所有对话整理成"时间＋谁说了什么"，交给 `claude -p --model haiku` 写回顾。整个过程不会拖慢你开对话。
3. 回顾写好之后，你在这个新对话发出下一句话时，`UserPromptSubmit` hook 会把回顾附在你的话后面交给 Claude。发出一次就清掉，之后不会再发。
4. 没隔够时间就什么都不做，对话结束时也什么都不做。

只有触发分析的那个新对话，或是回顾写好之后才开的对话，会收到回顾；已经开着的旧对话不会被打扰。

## 需求

- 支持 hooks 和 skills 的 Claude Code
- Python 3.8 以上，命令名是 `python`（如果你的是 `python3`，改一下 `.claude/settings.json`）
- 已登录的 `claude` 命令行。后台分析用的是 `claude -p`，会用到你自己 Claude 套餐的额度

## 安装

1. 把这个仓库的 `.claude/` 文件夹复制到你想启用的项目根目录。只会在这个项目生效，其他项目不受影响。
2. 如果项目原本就有 `.claude/settings.json`，把这里的 `hooks` 部分合并进去，不要整个覆盖。
3. 重新开一个 Claude Code 对话。
4. （可选）输入 `/mood name 妹妹`，让回顾用你喜欢的称呼。

Claude Code 只读"启动文件夹"的 `.claude/settings.json`，不会往上层找。如果你常在子文件夹开 Claude Code，要在那个子文件夹也放一份。

## `/mood` 命令

| 命令 | 作用 |
|---|---|
| `/mood` 或 `/mood status` | 看当前状态：开关、间隔、称呼、已分析到几点、有没有待发送的回顾、最近的错误 |
| `/mood on`／`/mood off` | 开启或关闭。关闭后不分析，也不发送回顾 |
| `/mood gap 4` | 把间隔改成 4 小时 |
| `/mood name 妹妹` | 设置回顾里怎么称呼你 |
| `/mood now` | 马上分析上次之后到现在的对话，直接显示给你看（看过的这份不会再自动发送） |
| `/mood show` | 看最新一份回顾 |
| `/mood clear` | 取消待发送的回顾 |

## 设置

设置保存在 `.claude/mood/config.json`，用 `/mood` 改就好，也可以直接编辑：

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 开关 |
| `gap_hours` | `6` | 多久没动静之后，开新对话才分析 |
| `model` | `"haiku"` | 传给 `claude -p --model` 的模型 |
| `user_name` | `"使用者"` | 回顾里对你的称呼 |
| `source_dirs` | 自动算出 | 要读 `~/.claude/projects/` 下面哪些文件夹的对话记录。默认是这个项目自己的文件夹（项目路径里非字母数字的字符换成 `-`） |

想改回顾的写法或语言，直接编辑 `.claude/hooks/mood_prompt.md`，里面的 `{name}` 会换成你的称呼。默认写繁体中文、200 到 400 字的段落。

## 文件

```
.claude/
├─ settings.json            挂上 SessionStart 和 UserPromptSubmit 两个 hook
├─ hooks/
│  ├─ mood_start.py         开新对话时判断要不要在后台分析
│  ├─ mood_analyze.py       读对话记录、调用小模型、写回顾
│  ├─ mood_inject.py        把待发送的回顾交给 Claude 一次
│  ├─ mood_ctl.py           /mood 命令的实际操作
│  └─ mood_prompt.md        给小模型的提示词
├─ skills/mood/SKILL.md     /mood 命令
└─ mood/                    运行后才出现：回顾、state.json、config.json、error.log
```

## 隐私

对话记录只在你电脑上读取。被挑出来的文字消息会通过你自己登录的 `claude` 命令行发给 Anthropic 分析，跟你平常用 Claude Code 一样。工具调用和工具结果不会发出。回顾保存在 `.claude/mood/`，`.gitignore` 已经排除这个文件夹，不会被你不小心推到 Git 上。

## 注意

- 回顾是另一个模型的判断，可能不准。注入时也会这样告诉 Claude，要它拿来调整说话方式，不要原文念给你听。
- 只在 Windows 上实际测试过。macOS 和 Linux 的代码有写，但没有测试。
- 分析失败会记在 `.claude/mood/error.log`，`/mood` 也会显示最近的错误。最常见的原因是 `claude` 命令行的登录过期。
