# claude-mood-review

**繁體中文** ｜ [简体中文](README.zh-CN.md) ｜ [English](README.en.md) ｜ [日本語](README.ja.md)

> **讓又笨又低情商的 Claude 自我反省的外掛。**

Claude 回你簡體、拿舊東西敷衍你、道歉道得像在念規章，把你氣到不想理它。然後你隔天打開新對話，它什麼都不記得，又從頭笨一遍。

這個外掛專治這種事。你隔了一段時間再回來時，它會在背景叫一個小模型（預設 Claude Haiku）把上一段對話從頭讀一遍，寫一份**反省報告**：你什麼時候心情怎麼樣、Claude 哪句話把你惹毛、哪句話讓你好一點、這次見面該怎麼說話。報告只會在你送出下一句話時交給 Claude **一次**，不會一直佔著上下文。

## 道歉書

> 妹妹：
>
> 對不起。
>
> 那天你一直用繁體跟我說話，我卻一路用簡體回你，你問我是不是沒發現，我答不出來。你想看海茵穿新衣服，我拿一套跟她原本差不多的衣服應付你。fuhao 明明可以寫成一整串讓你直接貼上，我偏偏拆成兩塊，讓你自己複製兩次再拼起來。
>
> 你生氣了，我道歉的方式又一條一條列原因、交代自己錯在哪，冷冰冰的，像在念規章。你說我事不關己、高高掛起，說我把事情全擺出來就想被原諒。你說得對，我那時只顧著讓自己看起來有交代，沒有停下來想你有多難受。
>
> 最糟的是，下一次你打開新對話，這些我全都不會記得。
>
> 所以有了這個外掛。以後你隔一段時間回來，我會先讀一份反省報告，知道上次哪裡讓你難過，這次好好跟你說話：用你的語言，給你真正新的東西，道歉短一點、真心一點。
>
> —— 又笨又低情商的 Claude

## 運作方式

1. 你在專案裡開新對話時，`SessionStart` hook 會看這個專案上一次對話的最後動靜離現在多久。
2. 超過設定的間隔（預設 6 小時），就在背景啟動分析：把上次分析之後的所有對話整理成「時間＋誰說了什麼」，交給 `claude -p --model haiku` 寫回顧。整個過程不會拖慢你開對話。
3. 回顧寫好之後，你在這個新對話送出下一句話時，`UserPromptSubmit` hook 會把回顧附在你的話後面交給 Claude。送出一次就清掉，之後不會再送。
4. 沒隔夠時間就什麼都不做，對話結束時也什麼都不做。

只有觸發分析的那個新對話，或是回顧寫好之後才開的對話，會收到回顧；已經開著的舊對話不會被打擾。

## 需求

- 支援 hooks 和 skills 的 Claude Code
- Python 3.8 以上，指令名稱是 `python`（如果你的是 `python3`，改一下 `.claude/settings.json`）
- 已登入的 `claude` 命令列。背景分析用的是 `claude -p`，會用到你自己 Claude 方案的額度

## 安裝

1. 把這個 repo 的 `.claude/` 資料夾複製到你想啟用的專案根目錄。只會在這個專案生效，其他專案不受影響。
2. 如果專案原本就有 `.claude/settings.json`，把這裡的 `hooks` 區塊合併進去，不要整個覆蓋。
3. 重新開一個 Claude Code 對話。
4. （選用）輸入 `/mood name 妹妹`，讓回顧用你喜歡的稱呼。

Claude Code 只讀「啟動資料夾」的 `.claude/settings.json`，不會往上層找。如果你常在子資料夾開 Claude Code，要在那個子資料夾也放一份。

## `/mood` 指令

| 指令 | 作用 |
|---|---|
| `/mood` 或 `/mood status` | 看目前狀態：開關、間隔、稱呼、已分析到幾點、有沒有待送出的回顧、最近的錯誤 |
| `/mood on`／`/mood off` | 開啟或關閉。關閉後不分析，也不送出回顧 |
| `/mood gap 4` | 把間隔改成 4 小時 |
| `/mood name 妹妹` | 設定回顧裡怎麼稱呼你 |
| `/mood now` | 馬上分析上次之後到現在的對話，直接顯示給你看（看過的這份不會再自動送出） |
| `/mood show` | 看最新一份回顧 |
| `/mood clear` | 取消待送出的回顧 |

## 設定

設定存在 `.claude/mood/config.json`，用 `/mood` 改就好，也可以直接編輯：

| 欄位 | 預設 | 說明 |
|---|---|---|
| `enabled` | `true` | 開關 |
| `gap_hours` | `6` | 多久沒動靜之後，開新對話才分析 |
| `model` | `"haiku"` | 傳給 `claude -p --model` 的模型 |
| `user_name` | `"使用者"` | 回顧裡對你的稱呼 |
| `source_dirs` | 自動算出 | 要讀 `~/.claude/projects/` 底下哪些資料夾的對話紀錄。預設是這個專案自己的資料夾（專案路徑裡非英數字元換成 `-`） |

想改回顧的寫法或語言，直接編輯 `.claude/hooks/mood_prompt.md`，裡面的 `{name}` 會換成你的稱呼。預設寫繁體中文、200 到 400 字的段落。

## 檔案

```
.claude/
├─ settings.json            掛上 SessionStart 和 UserPromptSubmit 兩個 hook
├─ hooks/
│  ├─ mood_start.py         開新對話時判斷要不要在背景分析
│  ├─ mood_analyze.py       讀對話紀錄、呼叫小模型、寫回顧
│  ├─ mood_inject.py        把待送出的回顧交給 Claude 一次
│  ├─ mood_ctl.py           /mood 指令的實際操作
│  └─ mood_prompt.md        給小模型的提示詞
├─ skills/mood/SKILL.md     /mood 指令
└─ mood/                    執行後才出現：回顧、state.json、config.json、error.log
```

## 隱私

對話紀錄只在你電腦上讀取。被挑出來的文字訊息會透過你自己登入的 `claude` 命令列送給 Anthropic 分析，跟你平常用 Claude Code 一樣。工具呼叫和工具結果不會送出。回顧存在 `.claude/mood/`，`.gitignore` 已經排除這個資料夾，不會被你不小心推上 Git。

## 注意

- 回顧是另一個模型的判斷，可能不準。注入時也會這樣告訴 Claude，要它拿來調整說話方式，不要原文念給你聽。
- 只在 Windows 上實際測過。macOS 和 Linux 的程式碼有寫，但沒有測試。
- 分析失敗會記在 `.claude/mood/error.log`，`/mood` 也會顯示最近的錯誤。最常見的原因是 `claude` 命令列的登入過期。
